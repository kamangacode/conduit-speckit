# Implementation Plan: Article Publishing and Discovery

**Branch**: `002-articles` | **Date**: 2026-09-06 | **Spec**: [spec.md](spec.md)

## Summary

Add the RealWorld article resource: authenticated authors create, update, and delete their
articles; readers retrieve, filter, paginate, and discover tagged articles. The implementation
extends the established Java hexagon, preserves User authentication and response conventions,
and proves behavior through independently purposed test lanes.

## Technical Context

**Language/Version**: Java 25 LTS

**Primary Dependencies**: Spring Boot, Spring Data JPA/Hibernate, Flyway, JUnit 5, Cucumber,
Testcontainers, Hurl, and Bruno.

**Storage**: PostgreSQL behind application ports and Flyway migrations; H2 remains the fast test
feedback database.

**Testing**: JUnit 5 for domain and application rules; MockMvc-backed Cucumber for business
scenarios; Testcontainers PostgreSQL/Flyway for persistence; Hurl for the independent RealWorld
contract; Bruno only verifies the derived collection remains synchronized.

**Target Platform**: JVM web service

**Project Type**: REST web service

**Performance Goals**: SC-005 verifies correct filtering and pagination over at least 100
articles; no separate latency target is specified.

**Constraints**: `Authorization: Token <jwt>`; JSON response content type; `422` field-keyed
errors; list representations omit `body`; anonymous `following` and `favorited` are `false`.

**Scale/Scope**: Five article/tag endpoints. Favorites, profiles, comments, and feed behavior
remain outside this feature.

## Constitution Check

*GATE: Passed before Phase 0 research and rechecked after Phase 1 design.*

- **I. RealWorld Contract Supremacy**: PASS. The duplicate-title contradiction was resolved in
  favor of `conformance/hurl/errors_articles.hurl`: duplicate titles receive distinct slugs.
- **II. Framework-Isolated Domain**: PASS. Article and tag rules remain plain Java under
  `domain/article`; JPA and Spring wiring remain in `infrastructure`.
- **III. Real HTTP Integration Tests**: PASS. Cucumber and JUnit use the HTTP boundary; Hurl
  independently validates the external contract.
- **IV. Externalized Secrets and Fail-Fast Configuration**: PASS. Article work reuses the
  existing JWT and database configuration without adding secrets.
- **V. Hashed Passwords Only**: PASS. Article projections use only the public User fields.

**Structure Decision**: `Article` and `Tag` are framework-free domain concepts. Application use
cases depend on article persistence ports and receive the authenticated User identity from the
HTTP adapter. The persistence adapter maps articles, tags, and their association. `ArticleController`
only maps the RealWorld envelopes and delegates to use cases.
